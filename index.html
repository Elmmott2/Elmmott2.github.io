Java Text Game

This project offers a small Java text based game. This game revolves around the player exploring rooms and collecting items. The main goal of the game, is to collect all items in one room with limited inventory and limited moves.

Java Full Store Application EXE

A store fully built in Java using JFrame and JPanel. This application offers a full manager panel for editing inventory, editing users, shopping for users, and generating reports. The store offers multiple items and a shopping cart.

Django Python T-Shirt Store

This project is a web application built using Python Django. It is a T-Shirt store with a built in admin panel to control inventory and users. Users are given the choice to order T-Shirts in multiple sizes, color, or fabrics of the ordered shirts.
